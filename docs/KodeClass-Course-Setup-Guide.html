How to set up a course, start to finish

A course lives in two places: you build the content in Moodle, and you control the price on your KodeClass admin dashboard. This guide walks through both — no code, no developer needed.

⏱ ~15 min per course 🔧 No technical skills 💡 Changes appear instantly

The two places you'll work

In Moodle

lms.kodeclass.com

Create the course, add lessons, videos, PDFs, and the course image. This is your content workshop.

On kodeclass.com

Admin → Pricing

Set what each course and bundle costs, and mark courses free. This is your storefront control.

✅

Log in to both first. Use your admin account on lms.kodeclass.com (Moodle) and your admin account on kodeclass.com (the dashboard). They are separate logins.

The steps

  1. 1
    In Moodle

    Create the course

    Site administration → Courses → Add a new course. Fill in these fields:

    1. Course full name — the title shown everywhere (e.g. Introduction to Graphics).
    2. Course short name — becomes the web address (e.g. intro-graphics → kodeclass.com/courses/intro-graphics). Use lowercase with hyphens.
    3. Course category — choose Beginner, Intermediate, or Advanced. This is what sets the price band.
    4. Course visibility — set to Show (hidden courses never appear on the website).
    5. Course image — upload a picture. It becomes the card thumbnail on the website.
    ⚠️

    The short name is the web link — don't change it later. Editing it after launch breaks the course's URL and any links you've shared. Pick it carefully the first time.

  2. 2
    In Moodle

    Add the lessons

    Open the course, switch on Edit mode (top-right). Add sections (e.g. Module 1), and inside each use Add an activity or resource:

    • File — PDFs, videos and images play inline on the site. PowerPoint/Excel files show as a Download button.
    • URL — paste a YouTube or Vimeo link and it embeds as a video player.
    • Text and media area or Page — for written lessons, with images that display right in the lesson.
    ⚡

    It shows up immediately. Save in Moodle and refresh the website — the new lesson is there. No waiting, no publishing step. For lessons meant to be watched or read on the page, prefer video or PDF over PowerPoint.

  3. 3
    On kodeclass.com

    Set the price

    Log in to kodeclass.com as admin → Dashboard → Pricing. Set three things:

    1. Per-course price — the cost of one single course, by level (Beginner / Intermediate / Advanced).
    2. Tier bundle price — the cost to unlock all courses in one level.
    3. Free courses — tick any course you want to offer at no cost.

    Click Save — prices update across the catalogue, course pages, and checkout instantly.

  4. 4
    On kodeclass.com

    Check it live

    • Open kodeclass.com/courses — your course card appears with its image, level, and price.
    • Click the course to see its full page, then Learn to preview the lessons.
    🎉

    That's it — the course is live. Free courses let learners start right away; paid courses send them through Paystack (M-Pesa or card) and enrol them automatically after payment.

How pricing is decided

The category you pick in Moodle (Step 1) chooses which price applies. To move a course to a different price band, just change its Moodle category.

If something looks wrong

What you seeThe fix
Course isn't on the websiteIn Moodle, check visibility is Show and the course is inside a Beginner / Intermediate / Advanced category.
Wrong price on the cardThe course is in the wrong category. Move it to the category whose price you want.
No thumbnail (placeholder image)No course image was uploaded. Edit the course in Moodle and add a Course image.
A file won't play on the pageIt's a PowerPoint/Excel file — those only download. Re-upload it as a PDF or video to play inline.
Learner sees "Enrol to access"Expected for paid courses before payment. If it should be free, tick it under Dashboard → Pricing → Free.
New lesson not showingRefresh the page. If still missing, confirm you saved it in Moodle and the section isn't hidden.

Quick recap: Build content & upload the image in Moodle → pick the category to set the price band → set the actual prices on kodeclass.com → Pricing → check it live. Everything about a course is now managed by you, no developer required.
